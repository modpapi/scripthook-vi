## 3. Does the entity class fit the name?

A handler resolves each entity reference through one of seven small functions, each checking one class (CPed, CVehicle, CObject, ...).
For every name whose reference signature starts with a Ped, Vehicle or Object, this compares that with the class the handler really asks for.
The class is used when scoring inferred names, so only the first three rows are an independent check.

Limits of this test: the hidden names are natives that the guide could name, so they exist in GTA V or RDR2. The handlers that are still unnamed
are likelier to be new, so the "absent" table is the closer estimate for them.
